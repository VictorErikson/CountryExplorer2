# Country Explorer

A React + TypeScript app for exploring the world's countries. Browse countries by region, view details on a map, save favourites to a personal collection, and test your knowledge with a country quiz or a geo-guessing game — complete with a leaderboard.

Built with Vite, React Router, Redux Toolkit, and Leaflet.

## Getting started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in your API keys before running.
